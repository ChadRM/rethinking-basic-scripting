I wrote the script to `/tmp/cleanroom-j8qh/add-backup-server-host.sh` and made it executable. It passes a bash syntax check, but I haven't run it or tested it against a real hosts file, because it changes `/etc/hosts` on whatever machine it runs on.

What it does:
- **Gets root:** if you're not root, it restarts itself with `sudo`.
- **Safe to rerun:** if `10.0.0.9 backup-server` is already there, it says so and exits without changing anything.
- **Backs up first:** before any change, it copies the file to `/etc/hosts.bak.<timestamp>`.
- **Fixes a wrong entry:** if `backup-server` is listed under a different IP, it deletes that whole line. Any other names on that line are deleted with it.
- **Adds the entry:** it appends `10.0.0.9<TAB>backup-server` to the end of the file.

Run it with:
```bash
./add-backup-server-host.sh
```

If you want this on a specific host, tell me which one and I'll deploy and run it there.
#!/usr/bin/env bash
# Add (or update) the backup-server entry in /etc/hosts.
# Idempotent: safe to run repeatedly.
set -euo pipefail

HOSTS_FILE="/etc/hosts"
IP="10.0.0.9"
NAME="backup-server"

if [[ $EUID -ne 0 ]]; then
    exec sudo -- "$0" "$@"
fi

# Already correct? Nothing to do.
if grep -qE "^[[:space:]]*${IP//./\\.}[[:space:]]+([^#]*[[:space:]])?${NAME}([[:space:]]|$)" "$HOSTS_FILE"; then
    echo "$NAME -> $IP already present in $HOSTS_FILE"
    exit 0
fi

cp -p "$HOSTS_FILE" "${HOSTS_FILE}.bak.$(date +%Y%m%d%H%M%S)"

# If the name is mapped to a different IP, remove that mapping first.
if grep -qE "^[^#]*[[:space:]]${NAME}([[:space:]]|$)" "$HOSTS_FILE"; then
    echo "Replacing existing $NAME entry"
    sed -i -E "/^[^#]*[[:space:]]${NAME}([[:space:]]|$)/d" "$HOSTS_FILE"
fi

printf '%s\t%s\n' "$IP" "$NAME" >> "$HOSTS_FILE"
echo "Added $NAME -> $IP to $HOSTS_FILE"
